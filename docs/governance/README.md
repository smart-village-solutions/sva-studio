# Governance

## Bereichsvertrag

| Merkmal        | Festlegung                                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Zweck          | Verbindliche Regeln für Beiträge, Branches, Reviews, Evidenz, Freigaben und Delivery-Governance                                                          |
| Zielgruppe     | Maintainer, Reviewer, Release-Verantwortliche und Beitragende                                                                                            |
| Autorität      | Führend für Prozess- und Freigaberegeln; `AGENTS.md` und `DEVELOPMENT_RULES.md` bleiben für ihre ausdrücklich geregelten Vorgaben zusätzlich verbindlich |
| Ownership      | Repository-Maintainer und die jeweils benannten Governance-Verantwortlichen                                                                              |
| Pflege-Trigger | Änderungen an Branch Protection, Merge-Gates, Review-, Evidenz-, Preview- oder Contributor-Prozessen                                                     |

Betriebliche Schrittfolgen gehören nach [Betrieb](../operations/README.md); technische Implementierungsanleitungen nach [Entwicklung](../development/README.md).
