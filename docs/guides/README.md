## Vollständigkeitsregel

Jede direkt unter `docs/guides/` liegende Datei außer diesem Index muss genau einmal in der Tabelle stehen. Neue allgemeine Guides sind nicht zulässig; neue Inhalte werden unmittelbar dem zuständigen Bereich zugeordnet. Änderungen am Inventar benötigen einen dokumentierten Zielpfad und dürfen den kanonischen Rolloutpfad nicht verändern.
