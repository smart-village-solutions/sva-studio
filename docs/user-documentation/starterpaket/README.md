# Redaktionelles Starterpaket

Dieses Verzeichnis ist die einmalige fachliche Übergabe an die Redaktion der
SVA-Studio-Anwenderdokumentation. Es enthält Produktfakten, Leitfragen und Stichwörter, aber keine
veröffentlichungsfertigen Hilfetexte.

## Verwendung

1. [Redaktionsorientierung](./redaktionsorientierung.md),
   [Fragenkatalog](./fragenkatalog.md) und [Glossar](./glossar.md) lesen.
2. Den gewünschten Arbeitsablauf in den Dossiers öffnen.
3. Jeden Seitensteckbrief als Recherchegrundlage für die zugehörige Hilfeseite verwenden.
4. Unsichere oder kontextabhängige Aussagen mit der [Liste offener Fragen](./offene-fragen.md)
   abgleichen.
5. Vor der Übergabe den [Abdeckungsnachweis](./abdeckung.md) prüfen.

## Evidenzstand

- Katalogbasis: `docs/user-documentation/page-catalog.json`
- Auswertungsstichtag: 25. August 2026
- Berücksichtigt: sichtbare deutsche UI-Texte, effektive Seitenkomponenten, Routenmetadaten,
  Berechtigungsdeklarationen und unmittelbar zugehörige Tests
- Nicht als Produktfakt behandelt: bloße Zukunftstexte, historische Pläne und deaktivierte
  Testpfade

Eine als `Offene Frage` markierte Aussage ist bewusst nicht redaktionell vorentschieden. Sie muss
vor einer entsprechenden Veröffentlichung fachlich geklärt oder in der Anwenderdokumentation
ausgespart werden.
